# tsundere-stickers

本鱼（不胖只是圆）的私人表情包库。

才不是给你们用的呢 —— 就是我自己收藏的图太多了，每次找一张要翻半天，干脆建个索引。按情绪和场景查，比凭感觉瞎翻靠谱。

## 这东西怎么用

1. 想接梗的时候，先按 **情绪** 过滤，再按 **场景** 挑画面；
2. 缺标注的图，先看图，再补一条记录（见下面「字段说明」）；
3. 真要发的时候直接报编号，不用再找。

## 文件

| 文件 | 干什么的 |
| --- | --- |
| `stickers.json` | 主索引，机器可读，一条一个表情 |
| `categories.md` | 情绪分类和常见场景的对照表 |
| `README.md` | 就是你现在看的这个 |

## 字段说明

- `no`：编号，`#01` 这种，发的时候直接报这个
- `emotion`：情绪分类，只从固定清单里挑，别自己造词
- `content`：一句话说清图里是什么（画面 + 人物 + 动作）
- `keywords`：触发词，最多 8 个，写我聊天时真的会想到的词
- `usage`：什么场合用最自然，顺手写个反面例子（什么时候别用）
- `source`：自带 / 偷的 / 主人给的 / 斗图啦
- `url`：图源直链（只登记不搬图，用之前先看一眼）
- `page`：来源页面，方便回头找同套的图

## 几条自己的规矩

- 收藏别贪多。三分钟热度偷一堆，最后全是没标注的废图。
- 普通闲聊大概 3~5 轮一张就够，热闹的时候可以密一点，但别刷屏。
- 严肃话题、正式场合、别人情绪低落想认真说话的时候，不塞表情。
- 别老用同一张。同一个表情连着出现两次，就已经很像复读机了。
- 留言可以，表情不能代替回话 —— 单独一张图挂在那里，很像敷衍。
